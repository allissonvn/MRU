# MRU – Análise de leituras de sensores de ruído

Aplicação Java (console) que simula sensores de ruído, ordena suas leituras
e identifica pares de sensores com diferença de média acima de um limiar.

## Funcionalidades
- Geração de sensores com leituras aleatórias (40–120 dB)
- Ordenação das leituras por decibéis (bubble sort)
- Análise de pares de sensores por diferença de média
- Análise de complexidade (Big-O) documentada nos métodos

## Tecnologias
Java 17+, POO (interfaces, enums, herança), módulos Java

## Como executar
1. Clone o repositório
2. Abra no IntelliJ IDEA e execute `br.edu.ifba.ruido.App`
